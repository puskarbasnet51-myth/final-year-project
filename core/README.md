# FeedForward 🍽️
**Fresh Individual Food Donation Management Platform**

A web-based platform that connects individuals who wish to donate 
fresh home-cooked or restaurant-ordered meals with NGOs, orphanages, 
and old age homes in need.

## Tech Stack
- Backend: Django 4.x (Python)
- Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
- Database: MySQL 8.0
- AI: Smart Matching Algorithm (scikit-learn)

## Setup Instructions
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure MySQL in settings.py
4. Run migrations: `python manage.py migrate`
5. Create superuser: `python manage.py createsuperuser`
6. Start server: `python manage.py runserver`
7. Visit: http://127.0.0.1:8000

## User Roles
| Role | Description |
|------|-------------|
| Donor | Individual who donates fresh home-cooked or restaurant-ordered meals |
| Receiver | NGO, orphanage, old age home, or shelter that needs food support |
| Admin | Platform manager who monitors donations and generates reports |
